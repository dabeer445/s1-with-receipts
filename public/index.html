How it works

Where the receipts come from

  1. The filing is split up. All 443 pages become about 1,000 passages, each tagged with its section, heading and printed page number.
  2. Your question finds passages. Plain keyword search picks the most relevant ones. No embeddings, nothing hidden.
  3. The model may only quote. Claude answers with sentences copied from those passages, plus one short line summarising them.
  4. Code checks every quote. Each one must match the filing word for word. Anything that doesn't is removed, and if nothing survives you're told the filing doesn't say.
